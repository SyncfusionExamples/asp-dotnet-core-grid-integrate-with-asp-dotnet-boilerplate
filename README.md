# SyncfusionGrid

## Repository Description
A practical demonstration of integrating Syncfusion EJ2 Grid with ASP.NET Boilerplate (ABP) framework featuring Domain Driven Design and data binding.

## Overview
This repository showcases Syncfusion EJ2 Grid integration into an ABP-based ASP.NET Core application with local and remote data binding.

## Features
- **EJ2 Grid**: Syncfusion EJ2 Grid with ABP framework
- **Data Binding**: Local JSON and remote API binding
- **Domain Driven Design**: Clean DDD architecture

## Project Prerequisites
- **[.NET 8.0+ SDK](https://dotnet.microsoft.com/download/dotnet)**
- **[Node.js (v18 or 20)](https://nodejs.org/en)**

## Installation

```
git clone https://github.com/SyncfusionExamples/asp-dotnet-core-grid-integrate-with-asp-dotnet-boilerplate
cd asp-dotnet-core-grid-integrate-with-asp-dotnet-boilerplate
dotnet restore
abp install-libs
```

## Running the Application

1. Open `SyncfusionGrid.sln` in Visual Studio
2. Set `SyncfusionGrid.Web` as startup project
3. Run the application (F5)
